# Student Grade Calculator

## Description

This is a simple Student Grade Calculator made using HTML, CSS, and JavaScript.

The program allows the user to enter a student's name, quiz grade, assignment grade, and exam grade.

It calculates the average grade and displays the student's result.

## Features

- Enter student name
- Enter quiz grade
- Enter assignment grade
- Enter exam grade
- Calculate average
- Display student result

## Technologies Used

- HTML
- CSS
- JavaScript

## Grade System

- 90 - 100 = Excellent
- 75 - 89 = Passed
- Below 75 = Failed
